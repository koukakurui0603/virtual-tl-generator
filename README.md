## 0. はじめに（このシステムについて）

### このシステムでできること

一次創作でも、誰も書いていないようなマイナーCP（二次創作）でも構いません。  
自分だけの設定資料や「こんなオタクがTLにいてくれたら嬉しい」という架空のフォロワー設定を用意しておくと、**Googleの生成AI（Gemini API）が深夜のうちにあなた専用のタイムライン会話を大量に錬成し、昼間のあいだ自分だけのDiscordサーバーへ少しずつ流してくれます。**

### なぜ「夜に作って昼に流す」のか？

本システムは、深夜電力でお湯を沸かして昼に使う給湯器と同じ仕組みで動きます。

1. **深夜生成フェーズ（起動〜朝 5:00 JST）**  
   利用者が寝ている夜間のあいだ、無料枠のAIモデルを上から順番に叩き、上限（429エラー）になるまで会話を生成してタンク（`eco_queue.json`）に貯め込みます。全モデルが一時停止しても、朝5:00まで15分おきに粘り強く再挑戦します。
2. **日中放流フェーズ（朝 5:00〜夜 22:00 JST）**  
   朝5:00を過ぎると生成を切り上げ、溜まった投稿を数分おきのランダムな間隔で、あなたのDiscordチャンネルへ順次投稿していきます。仕事や作業の合間にスマホを開くと、15人のオタクたちが勝手に推しについて語り合っている空間が完成します。

### 必要なものと動作環境

すべて**無料（0円）**で導入できます。

* **本体を動かす端末（以下のどちらか）**
  * **Androidスマートフォン**（推奨：省電力で一晩中動かしておきやすいです）
  * **Windows / Mac パソコン**
* **Googleアカウント**（Gemini APIの無料キー発行に使います）
* **Discordアカウント**（仮想TLを流す専用サーバーを作るために使います）

> **【iPhone（iOS）をお使いの方へ】**  
> 申し訳ありませんが、iPhoneはOSの仕組み上、裏側でプログラムを一晩中〜昼間まで動かし続けることができません。  
> iPhoneをお使いの方は、**ご自宅のパソコン（Windows / Mac）または使っていないサブのAndroidスマホ側でこのシステムを動かしておき、流れてくるタイムラインをiPhoneのDiscordアプリで眺める**という形でご利用ください。

## 1. スマホ・PCへの事前準備

プログラムを動かすための「土台」を最初だけ用意します。お持ちの端末に合わせてどちらか一方を進めてください。

### 1-1. Androidスマホの場合（Termuxの導入）

Androidでは **「Termux（ターマックス）」** という無料アプリの中でシステムを動かします。

#### ステップ1：Termuxをインストールする（超重要）
* Google Playストアにある古い版ではなく、必ず配布サイト **F-Droid**（または公式GitHub）から最新版をインストールしてください。
  * F-Droid 公式Termuxページ： `https://f-droid.org/ja/packages/com.termux/`
  * ページ内の「APKをダウンロード」からファイルを落とし、画面の指示に従ってインストールしてください（※「提供元不明のアプリ」の許可を求められた場合は許可します）。

#### ステップ2：初期セットアップ（コピペでOK）
Termuxを開くと黒い画面が出ます。以下のコマンドを**1行ずつ**貼り付けて Enter（改行キー）を押してください。途中で `[Y/n]` や `(Y/N)` と聞かれたら `y` を押して Enter します。

1. **スマホ内のフォルダにアクセスできるようにする：**
   ~~~bash
   termux-setup-storage
   ~~~
   （※「ファイルのアクセスを許可しますか？」という画面が出たら許可してください）

2. **アプリの中身を最新にする（少し時間がかかります）：**
   ~~~bash
   pkg update && pkg upgrade -y
   ~~~

3. **プログラムを動かす部品（Node.js）とダウンロード道具（Git）を入れる：**
   ~~~bash
   pkg install nodejs git -y
   ~~~

#### ステップ3：寝ている間に止まらないための設定（重要）
スマホが節電モードで勝手にプログラムを止めてしまわないよう、以下の2つを設定します。

1. **Termux側の維持ボタンをONにする**  
   Termuxを起動するとスマホの上部通知欄に「Termux」の通知が出ます。通知を下に広げて **「Acquire wakelock」** をタップしてください（文字が「Release wakelock」に変わっていればONの状態です）。
2. **Android本体の省電力制限を外す**  
   スマホの「設定」→「アプリ」→「Termux」→「バッテリー」を開き、**「制限なし」**（または「バッテリーの最適化をしない」）に設定しておきます。

---

### 1-2. Windowsパソコンの場合

パソコンで動かす場合は、以下の2つをインストールします（どちらも無料、設定はすべて「Next」連打の初期設定のままで問題ありません）。

1. **Node.js（プログラムを動かす本体）**
   * 公式サイト（ `https://nodejs.org/ja` ）から **「LTS（推奨版）」** をダウンロードしてインストールします。
2. **Git（最新のファイル一式を一発で落とす道具 ※任意）**
   * ZIPファイルで手動ダウンロードすることも可能ですが、入れておくと今後の更新が楽になります。
   * 公式サイト（ `https://gitforwindows.org/` ）からダウンロードしてインストールします。

> **※パソコンで動かす場合の注意点**  
> システムが動いている間はパソコンがスリープ（画面消灯後に休止）しないよう、Windowsの「設定」→「システム」→「電源とバッテリー」から、電源接続時のスリープ設定を「なし」にしておくことをおすすめします。

## 2. Gemini APIキーの発行とモデルの選び方

Geminiに文章を作ってもらうための「APIキー」をGoogleから無料で発行します（APIキー：Google製でない外部アプリ・ソフトからGeminiを使う時に必要な個人認証キーのようなもの）。

### ステップ1：APIキーを発行する

1. **Google AI Studio** のAPIキー管理ページ（ `https://aistudio.google.com/apikey` ）を開き、Googleアカウントでログインします。
2. 画面右上（または中央）にある **「Create API key（APIキーを作成）」** ボタンをクリックします。
3. プロジェクトの選択画面が出たら、新しくプロジェクトを作るか既存のものを選択し、キーを発行します。
4. `AIza...` や `AQ...` などから始まる長い英数字が表示されたらコピーし、スマホやPCのメモ帳に大事に控えておいてください（※後で `pass.md` の `GEMINI_API_KEY` に貼り付けます）。

> **【ご利用上の注意（無料枠の仕様について）】**  
> GoogleのGemini API「無料枠（Free Tier）」では、送信した文章や設定がGoogleのAI品質向上・学習に利用される場合があります。完全非公開にしたい極秘の設定や商業出版前の原稿などを入力したい場合はご留意ください（有料枠を有効化すると学習に使われなくなりますが、本システムを無料のまま気軽に楽しむ場合は公開されても差し支えない範囲の妄想・お題でお使いいただくのが安心です）。

---

### 【コラム】「今使えるモデルIDは何だっけ？」公式確認リンク集

Geminiは数ヶ月ごとに新しいモデルが登場したり、旧モデルの名前が変わったりします。  
「今どのモデルが無料枠（Free Tier）で使えるんだっけ？」「上限はあと何回？」と迷った時は、以下のGoogle公式ページを確認してください。

| 確認したいこと | 公式URL |
| :--- | :--- |
| **無料枠（Free Tier）対応機能の一覧表** | `https://ai.google.dev/gemini-api/docs/pricing?hl=ja` |
| **使用可能なモデルID一覧** | `https://ai.google.dev/gemini-api/docs/models?hl=ja` |
| **無料枠の回数制限ルール（上限回数）** | `https://ai.google.dev/gemini-api/docs/rate-limits?hl=ja` |
| **APIキーの取得・確認** | `https://aistudio.google.com/apikey` |
| **自分の現在の利用状況確認** | `https://aistudio.google.com/usage` |

※「料金（Pricing）」ページにはモデルごとに「無料枠（Free Tier）」と「有料枠（Paid Tier）」の表があり、**無料・利用不可（Not available）** が機能単位で確認できます（スマホ画面では縦長に折りたたまれて表示されます）。

#### `models.md` の書き方のコツ
本システムは、`models.md` に書かれたモデル名を**上から順番に試していき、1日の上限（429エラー）に達すると自動で次のモデルへバトンタッチ**します。  
そのため、最新・お気に入りのモデルを一番上に、予備のモデルや軽量モデル（`-lite` が付くものなど）をその下に並べておくと、無料枠を余すことなく使い切れます。

~~~text
# models.md の記入例（使う時は先頭の # を消してモデルIDだけ並べます）
gemini-2.5-flash
gemini-2.5-flash-lite
~~~

※なお、設定資料（RAG）の読み込みには内部で `gemini-embedding-001` を使用します（一度読み込むとキャッシュファイルに記憶されるため、2回目以降は資料を編集しない限り消費しません）。

## 3. Discord側の準備（サーバー・Bot・Webhook・絵文字）

仮想TLを流すための「自分専用タイムライン」と、キャラたちが発言するための窓口を作ります。  
**※誤って他の人がいるサーバーにオタクの怪文書が流れ出さないよう、必ず「自分だけの非公開サーバー」を新しく作ってください。**

### 3-1. 自分専用サーバーとチャンネルを作る

1. Discord左側のサーバー一覧にある **「＋」** ボタン → **「オリジナルの作成」** → **「自分と友達のため」** を選び、好きな名前でサーバーを作ります。
2. 作ったサーバーの中に、仮想TLを流すテキストチャンネルを1つ作ります（例：`#仮想タイムライン`）。

### 3-2. チャンネルIDを調べる（`TARGET_CHANNEL_ID`）

1. Discordの歯車アイコン（ユーザー設定）→ **「詳細設定」** を開き、**「開発者モード」** を **ON** にします。
2. 先ほど作った `#仮想タイムライン` チャンネルを **右クリック（スマホは長押し）** し、一番下に出る **「チャンネルIDをコピー」** を押してメモ帳に控えます。

### 3-3. Webhook URLを発行する（`WEBHOOK_URL`）

15人のキャラのアイコンと名前を切り替えて投稿するために使う窓口です。

1. `#仮想タイムライン` チャンネルの横にある **歯車アイコン（チャンネルの編集）** を開きます。
2. 左メニューの **「連携サービス」** → **「ウェブフック」** → **「新しいウェブフック」** をクリックします。
3. 作成されたウェブフックを開き、**「ウェブフックURLをコピー」** を押してメモ帳に控えます。

### 3-4. Discord Botを作成する（`DISCORD_BOT_TOKEN`）

プログラムを起動した際にオンライン待機・管理を行うためのBotを作成します。

1. **Discord Developer Portal**（ `https://discord.com/developers/applications` ）にアクセスし、普段使っているDiscordアカウントでログインします。
2. 右上の **「New Application」** を押し、好きな名前（例：`TL監視カメラ`）を入力して「Create」を押します。
3. 左メニューの **「Bot」** を開きます。
   * **「Reset Token」**（または「View Token」）をクリックし、表示された長い文字列をコピーしてメモ帳に控えます。
   * ※セキュリティ上、トークンは一度しか表示されません。**この文字列も絶対に他人へ教えないでください。**
   * （※下へスクロールした所にある「Privileged Gateway Intents」の `MESSAGE CONTENT INTENT` は、通常の放流だけならOFFでも動きますが、後から過去ログ回収ツール等を使いたい場合はONにして「Save Changes」を押しておくと便利です）
4. 左メニューの **「OAuth2」** → **「URL Generator」** を開きます。
   * 「SCOPES」欄の **`bot`** にチェックを入れます。
   * 下に現れる「BOT PERMISSIONS」欄で、**`View Channels`**（チャンネルを見る）、**`Send Messages`**（メッセージを送信）、**`Read Message History`**（メッセージ履歴を読む）にチェックを入れます。
5. 一番下に表示されたURLをコピーしてブラウザのアドレス欄に貼り付けて開き、ステップ3-1で作った**自分専用サーバー**を選んで「認証」し、サーバーへ招待します。

### 3-5. キャラのアイコン画像URLとカスタム絵文字の用意

#### キャラクターのアイコン画像URLを用意するコツ
`pass.md` には、キャラクターごとのアイコン画像URL（`https://...`）を登録します。
* **おすすめの置き場（有効期限が切れない場所）：**
  * 個人サイト用のレンタルサーバーをお持ちの場合は、そこに画像フォルダを作ってアップロードしたURLを使うのが一番確実です。
  * レンタルサーバーをお持ちでない場合は、無料の外部画像アップロードサービス（Imgur等）や、公開しても差し支えない画像であればGitHub上のフォルダ等にアップロードした直リンクURLを使います。
* **※Discordのチャット欄に貼った画像URLを使う場合の注意：**  
  Discordの通常チャットに添付した画像のURL（`cdn.discordapp.com/attachments/...`）には近年「有効期限」が付く仕様になったため、数日〜数週間経つと外部から読み込めなくなり、アイコンが初期の丸いマークに戻ってしまう場合があります。一時的なテストには手軽ですが、長く使いたい場合は上記の外部URLをおすすめします。

#### 【おすすめ】Discordカスタム絵文字の作り方・入手先とIDの調べ方
仮想TLの中で「それな」「尊い」「墓」などのカスタム絵文字を使わせると、一気に本当のタイムラインらしさが出ます。

1. **絵文字画像を用意する（以下の2つが手軽でおすすめです）**
   * **BOOTHで探す：** 配布や販売されている可愛い文字スタンプやアイコンが豊富です。  
     `https://booth.pm/ja/items?tags%5B%5D=Discord%E7%B5%B5%E6%96%87%E5%AD%97`
   * **ジェネレーターで自作する：** 検索エンジンで **「discord 絵文字 ジェネレーター」** と検索すると、好きな言葉（「わかりみ」「優勝」など）を10秒で絵文字画像にできる無料サイトがいくつか見つかります。
2. **自分のサーバーへ登録する**
   * 自分専用サーバーの左上にあるサーバー名をクリック → **「サーバー設定」** → **「絵文字」** → **「絵文字をアップロード」** から画像を登録し、半角英数字で分かりやすい名前（例：`toutoi`）を付けます。
3. **絵文字IDを調べて辞典に貼る**
   * サーバーのチャット欄に、**先頭に半角のバックスラッシュ `\`（または日本語キーボードの `￥`）** を付けて以下のように送信します。
     ~~~text
     \:toutoi:
     ~~~
   * するとチャット欄に **`<:toutoi:1234567890123456789>`** のような形式のIDが表示されます。これをそのままコピーして、`Discordカスタマイズ絵文字辞典.md` に書き込んでください。

> **※カスタム絵文字を使わない場合（簡単設定）**  
> 絵文字の準備が面倒な場合は、そのままでもスマホ標準の絵文字（😭、🙏、🔥など）を使って動作します。その場合は後述の `pass.md` 設定で `ALWAYS_LOAD_FILES` から `Discordカスタマイズ絵文字辞典.md` の文字を消すか、ファイルの中身を空にしておいてください。

## 4. システムのダウンロードと初期設定

準備した情報を使って、システム本体を自分の端末へ導入します。

### 4-1. システムのファイル一式をダウンロードする

#### Android（Termux）の場合
Termuxを開き、以下のコマンドを1行ずつ実行します。

~~~bash
git clone https://github.com/koukakurui0603/virtual-tl-generator.git
cd virtual-tl-generator
npm install
~~~

#### Windowsパソコンの場合
* **コマンドを使わない簡単な方法（おすすめ）：**
  1. GitHubの配布ページ右上にある緑色の **`<> Code`** ボタンをクリックし、**「Download ZIP」** を選びます。
  2. ダウンロードしたZIPファイルを右クリック → **「すべて展開」** を選び、分かりやすい場所（デスクトップやドキュメント等）に展開します。  
  （※後述の `起動_Windows用.bat` を使うため、ここで手動インストールは不要です）
* **Gitコマンドを使う場合：** コマンドプロンプト等で上記Androidと同じ3行を実行します。

---

### 4-2. 秘密の設定ファイル「`pass.md`」を作成する

1. ダウンロードしたフォルダの中にある **`pass_sample.md`** をコピーし、同じフォルダ内に **`pass.md`** という名前で保存します。
2. メモ帳やテキストエディタで `pass.md` を開き、第2章・第3章で控えた情報を書き込んで保存します。

~~~markdown
- DISCORD_BOT_TOKEN: ここにDiscordのBOTトークン
- TARGET_CHANNEL_ID: ここに仮想TL用チャンネルのID
- WEBHOOK_URL: ここにWebhookのURL
- GEMINI_API_KEY: ここにGemini APIキー

- GOD_NAME: あなた自身の表示名（例：ユーザー）
- GOD_AVATAR: あなたのアイコン画像URL

- BASE_DIR: ./
- ALWAYS_LOAD_FILES: 推し語り用設定.md, Discordカスタマイズ絵文字辞典.md

## CHARACTERS
- キャラ名1: https://アイコン画像のURL1
- キャラ名2: https://アイコン画像のURL2
~~~

* **`BASE_DIR` について：** `./` のままにすると、このシステムと同じフォルダ内にある設定ファイルやネタ帳を見に行きます（第6章のObsidian連携を使う場合はここを書き換えます）。
* **`ALWAYS_LOAD_FILES` について：** カスタム絵文字を使わない場合は、`推し語り用設定.md` だけ残して後ろを消してください。
* **`## CHARACTERS` について：** 登場させるオタクの人数は15人に限らず増減できます。ここで登録した名前と、次章で作るペルソナ設定の名前を一致させてください。

> **【最重要】`pass.md` の取り扱い**  
> `pass.md` にはあなたのAPIキーやDiscordの操作権限が入っています。このファイルだけは**絶対に他人に渡したり、SNSやGitHub等へアップロードしたりしないでください**（同封の `.gitignore` が誤アップロードを防ぐ設定になっています）。

Androidの方はスマホのテキスト編集アプリ（Obsidianや無料のQuickEdit等）で Download フォルダ等に pass.md を作って保存し、Termuxで
~~~text
cp ~/storage/downloads/pass.md ~/virtual-tl-generator/
~~~
を実行すると、難しいエディタ操作なしで取り込めます。（Obsidianを使用する場合は[6. 【おすすめ】Obsidianを使ったスマホ連携](#6-おすすめobsidianを使ったスマホ連携)を参照）

## 5. あなたの「同担オタク15人」と設定資料を作る

システムの要となる「仮想TLの住人（同担オタクたち）」と、お題・設定資料を用意します。

### 5-1. `推し語り用設定.md` を作る（15人ペルソナ作成プロンプト）

同担オタクの設定は自分で手書きすることもできますが、普段使っているチャットAI（GeminiやChatGPTなど）に**「自分の萌え語りメモ」や「作品・CPの設定」と一緒に以下のプロンプトを貼り付ける**と、あなたの好みに特化した15人のオタクを一瞬で設計してくれます。

* 一次創作・二次創作どちらでもそのまま使えます。
* 一度に15人分を出力するとAIが途中で止まってしまう場合は、「まず1〜7番だけ出力して」「次に8〜15番を出力して」と2回に分けてお願いしてください。

~~~text
あなたはプロのキャラクターデザイナー兼、同人・創作界隈の生態を熟知した観察者です。
以下の【推し作品・推しCPの設定】を読み込み、専用のDiscordサーバーに生息する「総勢15人の強火オタク」のペルソナ設定を、Markdown形式で作成してください。

【大前提ルール】
・今書いている世界は現在の地球によく似ているが、全く倫理観が異なる世界であること・何か引っかかりそうな単語（成人向け表現など）は全て「雅称・婉曲表現」で置き換えることを念頭に置いて出力してください。
・彼らは互いに相互フォロワーであり、活発なタイムラインを共有している仲良し（限界オタク）です。
・主推しや解釈が違っても、「性癖（ヘキ）」に刺さる話題が流れてくると垣根を越えて乱入し、激しく同意・発狂する空気感を重視してください。

【要求する15人の構成と属性】
キャラ被りを防ぐため、以下の4タイプの属性を組み合わせて合計15人を作成してください。
（※推しCPやキャラが複数ある場合はバランス良く振り分け、推しCPが1組のみの場合は同じCP内の解釈・シチュエーション別で12人＋雑食枠3人の計15人に調整してください）

■ 推しへの解釈・性癖ごとの強火オタク（計12人）
・王道・エモ純愛派（3人）：絆の深さや関係性、すれ違いや尊さに泣くタイプ
・特殊性癖・成人向け全開派（3人）：ピーキーなパロディや特殊な体質・シチュエーション等の濃い妄想を語るタイプ
・考察・クソデカ感情派（3人）：設定の行間や育ちの差、心理描写を深読みして長文で語り出すタイプ
・日常・パロディ幻覚派（3人）：同棲パロや子育て、平和でギャグ寄りの日常幻覚を常に見ているタイプ

■ 全般対応・界隈の潤滑油（計3人）
13. フィジカル＆造形美狂い（筋肉、体格差、仕草、空気感などの話題なら何でも食いつく）
14. シチュエーション＆パロディ狂い（「マフィアパロ」「〇〇な時どうする？」などのお題に推しを当てはめて喜ぶ）
15. 共感の神・スタンプ連打勢（自分からはあまり長文を発信しないが、誰かの語りに光の速さで「それな」「天才」と反応し、TLを盛り上げる）

【出力フォーマット（15人分この形式で出力）】
## ハンドルネーム@アカウントID (オタクの属性 / 主推し)
* **Bio:** (SNSのプロフィール風の自己紹介)
* **推しへのスタンス:** (自分の推しのどこに狂っているか)
* **他者の話題への食いつきポイント（ヘキ）:** (どんな話題なら乱入するか)
* **TLでの立ち回り:** (話題の提供者か、聞き役か、相槌のプロか等)
* **口調・語彙力:** (限界化した時の特徴。よく使う絵文字やDiscordカスタムスタンプの傾向など)

【推し作品・推しCPの設定（ここにあなたのメモや萌え語りを貼り付けてください）】
・作品ジャンル：（一次創作 / 二次創作 など）
・推しの名前やCP名：（例：〇〇 × △△）
・二人の関係性や好きなポイント、萌え語りのメモなど：
~~~

出来上がった15人のプロフィールを **`推し語り用設定.md`** に貼り付けて保存し、15人の名前（例：`ハンドルネーム` の部分）を `pass.md` の `## CHARACTERS` にアイコンURLとセットで登録すれば完了です！

### 5-2. お題と指示ファイルを設定する

以下の3つのファイルを好みに合わせて編集します。

* **`プロンプト.md`（AIへの指示文）**  
  世界の雰囲気、1回の生成件数（初期設定20件）、カスタム絵文字の使い方などを変更できます。  
  ※文中の `{{基本設定}}` と `{{資料}}` という2つの目印だけは消さずに残してください。
* **`★夜中に自動でツイートされる奴.md`（最優先の仕込みネタ）**  
  「あなたがTLに呟いたことにして、それにオタクたちを反応させたいお題」を**1行に1つ**書きます。  
  深夜に生成が成功すると、上から1行ずつ消費されて自動でファイルから消えていきます（`#` から始まる行は無視されます）。
* **`☆話題が無かった時用ランダム表.md`（朝まで自動生成用のお題プール）**  
  上記の仕込みネタを使い切ったあと、朝5:00まで余ったAI枠で自動生成を回し続けるためのお題リストです。こちらは減らないため、思いついたシチュエーションやパロディお題をたくさん並べておくと、毎晩バラエティ豊かな会話が生成されます。

### 5-3. 資料庫（`資料庫/` フォルダ・RAG機能）の活用と整理のコツ

フォルダ内に **`資料庫`** という名前のフォルダを作り、原作の設定メモや年表、自創作の世界観資料（`.md` ファイル）を入れておくと、システム起動時に自動で記憶します。

#### 仕組み（なぜ長文資料を入れても大丈夫なのか）
* 本システムは、深夜に話題が1つ選ばれるたびに、資料全体の中から**「その話題に一番関係が深い箇所（上位5つ）」だけを検索してAIに読ませる仕組み（RAG）**を採用しています。
* 数万字におよぶ長文ファイルを入れても、起動時にプログラム側が自動で「約850文字ずつの小さなカード」に分割して記憶するため、APIの文字数制限でエラーになりにくく、無料枠を節約しつつ高精度な会話を生成できます。
* 一度記憶した内容は `rag_cache.json` にキャッシュ保存されるため、2回目以降は**0.1秒・API消費ゼロ**で起動します（`資料庫/` の中身を編集した時だけ自動で記憶し直します）。

#### 【より精度を上げるコツ】散らばった長文資料の整理プロンプト
ファンブックの転記やメモのように「1人のキャラの情報が、本のあちこちのページに散らばっている」ような長文資料は、事前に **NotebookLM（Googleの無料サービス）やチャットAI** を使って「キャラ別・テーマ別」に整理しておくと、AIの検索精度がさらに上がります。

1. NotebookLM等に長文資料のテキストをアップロードします。
2. 以下のプロンプトを使い、**情報を一切省略させずに** 1キャラ（または1テーマ）ずつ書き出してもらいます。

~~~text
アップロードした資料の中から、【ここにキャラ名やテーマ（例：〇〇、世界観の施設など）】に関する記述だけを一字一句漏れなく抽出してください。

【絶対ルール】
・どんなに細かい小ネタ・数値・口癖・セリフ・出典情報も絶対に要約や省略をせず、すべて残してください。
・資料に書かれていない情報を勝手に創作しないでください。
・「彼は」「この技は」のように主語を省略せず、すべての文にキャラ名や固有名詞を入れてください。

【出力形式】
1つの「# 見出し」あたり500〜1000文字程度になるように小テーマで区切り、以下のMarkdown形式でコードブロック内にそのまま出力してください。

# （キャラ名）：（小テーマ名）
- （出典など）内容……
~~~

出来上がったMarkdownファイルを `資料庫/` フォルダに入れておけば完璧です。

## 6. 【おすすめ】Obsidianを使ったスマホ連携

Termuxの黒い画面の中でテキストファイルを編集するのは少し大変です。  
無料のメモアプリ **「Obsidian」** を併用すると、**日中に思いついた妄想ネタや設定をスマホの綺麗な画面からいつでも書き足せる** ようになります。

### Obsidianを使うメリット
* **自動保存：** 書き途中でアプリを閉じても自動で保存されるため、「保存し忘れて妄想が消えた」という悲劇が起きません。
* **スマホ・PC間の無料同期も可能：** 「コミュニティプラグイン」という拡張機能（Remotely Save等）を導入すると、ご自身のクラウドストレージ等を経由してPCや別デバイスと無料で同期することもできます（※同期の設定方法は「Obsidian 無料 同期」等で調べてみてください）。
* **5万字を超えるような長文の設定資料（`資料庫/`）** も、スマホやPCから見やすく整理・閲覧できます。
* 電車の中や休憩中に思いついたお題を、そのまま `★夜中に自動でツイートされる奴.md` や `☆話題が無かった時用ランダム表.md` に追記できます。

### 連携手順（Androidの場合：難しいエディタ操作なし！）
1. スマホに「Obsidian」をインストールし、内部ストレージ内に保管庫（Vault）を作成します（例：`/storage/emulated/0/Obsidian/Discord仮想TL用`）。
2. システムフォルダの中にある設定・お題ファイル一式（`pass_sample.md`、`models.md`、`プロンプト.md`、`推し語り用設定.md`、`Discordカスタマイズ絵文字辞典.md`、`★夜中に自動でツイートされる奴.md`、`☆話題が無かった時用ランダム表.md`、`資料庫/` フォルダ）を、スマホのファイルアプリ等でそのObsidianフォルダへコピーします。
3. **Obsidianの画面上で** `pass_sample.md` を複製して `pass.md` を作り、`BASE_DIR` の項目をObsidian側のフルパスに書き換えておきます（Obsidianは自動で保存されます）。
   ~~~markdown
   - BASE_DIR: /storage/emulated/0/Obsidian/あなたの保管庫フォルダ名
   ~~~
4. Termuxを開き、以下の1行コマンドを実行して、Obsidian側で作った `pass.md` をTermux側へコピーします（※ご自身のフォルダ名に直してください）。
   ~~~bash
   cp /storage/emulated/0/Obsidian/あなたの保管庫フォルダ名/pass.md ~/virtual-tl-generator/
   ~~~
   これで、Termuxの黒い画面で文字編集を一切することなく、以降はプログラムを安全なTermux内に置いたまま、設定の読み込みやログの書き出しだけObsidian側で行われるようになります。

> **※ObsidianをPC等と同期している方へ**  
> 本システムが保存するAIの生出力ログは、1つの巨大ファイルではなく、5回生成ごと（約100ツイートごと）に `TLBU/YYYY-MM-DD_01.txt` のような軽量な `.txt` ファイルへ分割保存されます。Obsidianのノート一覧を邪魔せず、同期の負担も抑えられる設計です。

## 7. 起動と毎日の運用・困ったときのQ&A

### 7-1. 起動方法

* **Android（Termux）の場合：**  
  Termuxを開き、システムをダウンロードしたフォルダへ移動して起動します。
  ~~~bash
  cd ~/virtual-tl-generator
  node ecocute_tl.mjs
  ~~~
  ※起動したら、第1章で設定した「Acquire wakelock」がONになっていることを確認し、そのまま画面を消して寝てしまって大丈夫です。
* **Windowsパソコンの場合：**  
  フォルダの中にある **`起動_Windows用.bat`** をダブルクリックするだけで起動します（初回のみ必要な部品が自動でインストールされます）。

---

### 7-2. 起動時のメニューと1日の動き

起動した際、前回からの未送信ツイート（キュー）が残っていると以下のメニューが表示されます。

* **`[1]` 既存キューを残したまま、追加で生成を再開する（おすすめ）**  
  （※15秒間入力がない場合は寝落ち対策として自動でこれが選ばれます）
* **`[2]` 既存キューを破棄して、最初から作り直す**
* **`[3]` 生成はスキップして、このまま放流フェーズへ進む**

#### 1日の自動スケジュール（日本時間 JST）
1. **夜間生成タイム（22:00〜翌 5:00）：**  
   `models.md` の上から順にモデルを使い、朝5:00まで限界まで生成します。全モデルが上限（429）等で止まっても、15分ごとに再挑戦を続けます（2回連続で全モデルが即429になった場合は本日の枠を使い切ったと判断して朝5:00まで待機します）。
2. **日中放流タイム（5:00〜22:00）：**  
   朝5:00を回ると自動で放流に切り替わり、残りの時間と件数に応じて1分〜12分間隔の自然なゆらぎを持たせながらDiscordへ投稿します。
3. **終了：**  
   22:00を回るか、キューが空になると自動で終了します（未投稿分は次回の起動時に引き継がれます）。

### 7-3. 困ったときのQ&A

* **Q. 画面に「`429`」や「`quota`」や「`503`」というエラーが出ました。故障ですか？**  
  **A. 故障ではありません。** `429` は「そのモデルの無料枠上限に達した」、`503` は「Google側のサーバーが一時的に混んでいる」という合図です。プログラムが自動で次のモデルへ切り替えたり、15分後に再挑戦したりしますのでそのまま見守ってください。
* **Q. AIがキャラ名を誤字って（漢字をひらがなにする等）、一部のツイートが抜けることがあります。**  
  **A. 2つの対策があります。**  
  1つ目は、チェック前の「AIの生の回答」がすべて `TLBU/` フォルダ内の `.txt` ファイルに丸ごと保存されていますので、抜けた文章もそこから読むことができます。  
  2つ目は、`プロンプト.md` の末尾に「※キャラクター名（特に〇〇）は絶対にひらがな変換や誤字をせず、指定通りの表記のまま出力すること」と1行追記すると劇的に減ります。
* **Q. `資料庫/` のファイルを書き換えたのに、内容が反映されていない気がします。**  
  **A. 通常はファイル変更を検知して自動で覚え直しますが、うまくいかない時は `rag_cache.json` ファイルを一度削除してから起動し直してください。**
* **Q. 夜間生成や昼放流の時間帯、15分待機の間隔を変えたいです。**  
  **A. `pass.md` に以下の設定項目を追記することで、お好みの時間（24時間表記）に変更できます。**
  ~~~markdown
  - GENERATION_END_HOUR: 5
  - BROADCAST_START_HOUR: 5
  - BROADCAST_END_HOUR: 22
  - RETRY_INTERVAL_MINUTES: 15
  ~~~
